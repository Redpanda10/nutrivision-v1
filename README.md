# 🍎 About NutriVision AI

## 📌 Overview

**NutriVision AI** is an intelligent food recognition and nutrition tracking application that helps users monitor their diet using Artificial Intelligence.

The app allows users to:

* 📸 Scan food using the mobile camera
* 🤖 Detect food items using YOLO AI
* 📊 Track calories and nutrition
* ⚠️ Receive allergy & health warnings
* 💧 Monitor hydration
* 📈 Visualize nutrition analytics
* 🧠 Get AI-generated food insights

# 🧠 AI Architecture

## 🔍 YOLO Food Detection

A Python microservice is used for AI detection:

* YOLO model integration
* Image preprocessing
* Bounding box detection
* Confidence scoring

### Flow:

React Native → Node.js API → Python YOLO Service → Detection Result

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/Redpanda10/nutrivision-v1.git
```

## Frontend Setup

```bash
cd food-ai-app
npm install
npx expo start
```

## Backend Setup

```bash
cd n-backend
npm install
npm run dev
```

## Python AI Service

```bash
cd ai-service
pip install -r requirements.txt
python detect_service.py
```
